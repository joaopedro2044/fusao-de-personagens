⚡ Fusão de Personagens ⚡

Combine personagens e crie uma nova criatura!

🧬 Como funciona?

Neste projeto, você escolhe dois personagens e combina suas características para criar um personagem totalmente novo.

A atividade usa listas para guardar os personagens e recursão para percorrer uma lista de características.

🎮 Criador de fusões

Poderes:

    📚 O que são listas?

    Uma lista permite guardar vários elementos em uma única variável. Em Python, podemos criar uma lista usando colchetes. 

    personagens = ["Dragão", "Ninja", "Guerreiro"]

print(personagens[0])

    O resultado será "Dragão". Em Python, a contagem dos índices começa pelo zero.

    🔄 O que é recursão?

    Recursão acontece quando uma função chama a si mesma para resolver uma parte de um problema. É importante ter uma condição de parada para evitar chamadas infinitas. 

    def contar_lista(lista, indice=0):
    if indice >= len(lista):
        return

    print(lista[indice])
    contar_lista(lista, indice + 1)

personagens = ["Dragão", "Ninja", "Guerreiro"]
contar_lista(personagens)

    Nesse exemplo, a função mostra cada elemento da lista. Ela termina quando o índice chega ao final.

    🧠 Como o projeto funciona?

    1. As opções de personagens ficam organizadas em listas.
    2. O usuário escolhe dois personagens.
    3. O programa identifica os personagens escolhidos.
    4. Uma nova criatura é criada com poderes combinados.

    O site usa JavaScript para tornar a fusão interativa. Os exemplos de listas e recursão são escritos em Python para demonstrar os conceitos estudados na atividade.
